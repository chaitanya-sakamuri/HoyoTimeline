# 📅 Hoyo Timeline

A web application that helps players of HoYoverse games keep track of character birthdays

Currently supports tracking for:
- 🌿 Genshin Impact
- ⚡ Zenless Zone Zero
- (HSR on the way!!)

## 🌐 Live Demo

🔗 https://your-live-link-here

---

## ✨ Features

- 📅 View upcoming and ongoing banners
- 🎮 Support for multiple HoYoverse games
- 🔍 Clean and easy-to-use interface
- 📱 Responsive design for desktop and mobile
- ⚡ Fast loading with organized game data
- 🎨 Simple and modern UI

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/chaitanya-sakamuri/hoyo-timeline.git
```

Open `index.html` in your browser.

No additional setup is required.
